# CinAI Base Automation WF Plugin

Plugin đóng gói toàn bộ quy trình tự động hoá dựng Workflow trên `cinai.tv` từ Lark Base / Google Sheets:
- `omni-gemini-1-2-automation-wf/`: Skill đầy đủ 7 bước (Lark/Drive → Phân tích media → Chọn model theo thời lượng `1-15s` / `15-20s` / `20-30s` → Prompt 7 khối → Creative Intro `intro-clip` → Editly Pro 2-track 9:16 → Title Design Thumbnail `0` credit → Publish WF Share Template → So sánh & Đóng gói App).
- Hỗ trợ cài đặt thành plugin dùng chung trên Antigravity (`~/.gemini/config/plugins/cinai-base-automation-wf`) hoặc chạy trực tiếp trong workspace `Socalmedia`.
